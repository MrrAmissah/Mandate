# Project assets

Store Mandate-API brand and documentation assets here.

Recommended filenames:

- `mandate-logo.png` — primary transparent logo for the repository README and documentation
- `mandate-icon.png` — square icon for favicons, package listings, and application surfaces
- `architecture-overview.svg` — high-level system diagram
- `authorization-flow.svg` — mandate evaluation and approval flow
- `receipt-lifecycle.svg` — action receipt creation and verification flow

Keep source-quality assets where licensing permits, avoid embedding secrets or customer information, and prefer SVG or optimized transparent PNG files for documentation.
